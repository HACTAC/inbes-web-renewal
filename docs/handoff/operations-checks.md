# 運用点検と未使用ファイルの扱い

2026-10-09の本人方針：現行サイトに関係ないファイルは本番から削除する。現行TOPから参照される旧商品ページ、画像、説明書などは残す。NAS原本と非公開の復旧用退避は保持する。年代や名称だけで不要と判断しない。

## 確認状態

- 問い合わせの管理者宛メール・自動返信の実着信は本人確認済み。
- Mac/NAS同期は本人担当。完了の報告はまだない。
- Search Consoleは公開サイト側のXML・14URL・robots・canonicalを確認。Google側の現在の取得/登録状況は管理画面に接続できず、本人のステータス/最終読み込み日/検出ページ数の回答待ち。
- 依存auditは7（critical0/high5/moderate2）。互換性を保った追加修正は今回見つからず。条件判断は [依存確認](../security/dependency-review-2026-10-09.md) を参照。

## 旧ダウンロード処理の撤去

`download/download.php` は現在の主要42ページの導線とNAS/current source/publicから参照されていない。現行LA02W説明書はPDFへの直接リンクで正常。旧PHP公開コピー1件を退避・再取得SHA競合確認・独立レビュー後に本番から削除し、再転送除外へ追加した。修正案は公開せず、`legacy-public` の管理対象にも追加しない。NAS原本は保持する。

復旧時は本番に別のファイルがないことと復旧先の型を確認し、非公開退避の原本だけを転送してSHAを確認する。成功後、NAS最新active除外からこのパスだけを解除し、ほかの最新除外を保持する。Git内のpath-only referenceは最新NAS除外の代用にしない。

## 繰り返し確認

週1回を目安に、主要ページ、現在のページから得たサイト内リンク、説明書の到達、依存監査と互換修正版の公開を確認する。HTTP正常だけで画面や実メールが正常と断定しない。実際の更新時はPC/mobile、メニュー/スライダー、フォーム模擬操作を検証し、[NAS差分公開手順](nas-operations.md) を使用する。

本セッションに定期自動実行の操作機能がなく、自動監視は未設定。NASの作業記録に手動再実行手順と結果を保存している。自動化が利用可能になった際は、変化なしでは通知せず、障害や新たな要対応事項だけを通知する。

既存の依存更新に伴う16HTML/新CSSの差分は今回のPHP撤去に混ぜていない。公開HTML・画像・PDF・メール設定の変更はない。
