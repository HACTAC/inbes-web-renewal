# 画像素材一覧

## 目的

各ページの画像を、確定素材に差し替えるための確認表である。
現時点では、製品一覧の画像のみ確定素材を使用している。その他は共通のプレースホルダーで表示する。

## 画像ルール

- 基本比率: 3:2
- Heroや縦長の見せ場: 必要に応じて4:5
- 横長の補助ビジュアル: 16:9
- 商品画像: `object-contain`を基本とする
- 仕事風景・使用シーン: `object-cover`を基本とする
- モバイルでは、商品本体や人物の顔が切れないことを優先する

## 必要素材

| 配置 | 現状 | 推奨素材 | 備考 |
| --- | --- | --- | --- |
| TOP 自社製品 | プレースホルダー | 製品または製品群の使用シーン | 入口として商品が伝わること |
| TOP 商品化支援 | プレースホルダー | 開発・仕様確認・パッケージ制作の風景 | 企業向けの実務感を優先 |
| 開発支援 Fields | プレースホルダー | 分野を代表する製品写真 | 6カテゴリに対応 |
| 開発支援 Worksカルーセル | プレースホルダー | 開発実績の商品画像 | 複数画像対応予定 |
| 開発実績一覧 | プレースホルダー | 各案件の商品画像 | 掲載許可と公開範囲を確認 |
| 会社概要 Message | プレースホルダー | 商品・開発風景・仕事風景 | 代表者写真は使用しない |

## 確認が必要な事項

- 実績ごとの掲載可否
- クライアント名と法人格
- 写真の使用権限
- 画像内に含まれるロゴや製品情報の公開可否
- 支援内容と写真の対応関係
